`configs/data/lichess-2025-01-02.yaml`, `tests/unit/test_{config,fetch,manifest}.py`.

**Interfaces producidas:**
- `rukh.config.BaseConfig(BaseModel)` con `model_config = ConfigDict(extra="forbid")`;
  `load_yaml(path: Path, model: type[T]) -> T`.
- `rukh.data.fetch.FetchConfig(BaseConfig)`: `dataset: str = "Lichess/standard-chess-games"`,
  `months: list[str]` (formato `YYYY-MM`), `min_elo: int = 1800`, `min_base_seconds: int = 180`,
  `terminations: list[str] = ["Normal", "Time forfeit"]`, `min_plies: int = 20`,
  `exclude_variants: bool = True`, `out_dir: str = "data/raw"`, `limit: int | None = None`.

  por mes (UNION ALL), filtros `WhiteElo >= min_elo AND BlackElo >= min_elo`,
  `CAST(split_part(TimeControl,'+',1) AS INTEGER) >= min_base_seconds`, `Termination IN (...)`,
  `Event NOT ILIKE '%variant%'` cuando `exclude_variants` (nota: la exclusión de variantes se afina en P1),
  y `LIMIT` si procede. El conteo de plies se hace en P1 tras convertir a UCI (documentar en docstring).

- `run(cfg, dry_run: bool) -> FetchPlan`: con `dry_run=True` no toca red ni disco.
- `rukh.data.manifest.Manifest`: `dataset, months, filters: dict, counts: dict[str,int],
  files: list[FileHash{path, sha256, bytes}], created_at: datetime, rukh_version`.
- CLI: `rukh data fetch --config configs/data/lichess-2025-01-02.yaml --dry-run` imprime el plan.

## Tarea 4: `rukh` · Stockfish: descarga, detección y `rukh engine check`

**Ficheros:** `scripts/get_stockfish.py`, `src/rukh/engine.py`, `tests/unit/test_engine.py`.

  `https://github.com/official-stockfish/Stockfish/releases/download/sf_19/stockfish-windows-x86-64-universal.zip`
  (o el asset linux `stockfish-ubuntu-x86-64-avx2.tar` en Linux) a `tools/stockfish/` y deja el

  `chess.engine.SimpleEngine.popen_uci`, lee la opción `UCI_Elo` (min/max), configura
  `UCI_LimitStrength=True, UCI_Elo=elo`, juega `plies` medias jugadas contra un jugador aleatorio
  (`random.Random(seed)`), y devuelve el resultado; lanza `EngineNotFound` si no hay binario.
